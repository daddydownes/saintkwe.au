# Saint KWE website

Final static source: selected After hours homepage, opening video lettering, music links, responsive concert gallery and five-video flight experience.

## Run
Serve this folder with any static web server, then open index.html through that server. For Python: `python -m http.server 4173`. Open http://localhost:4173/.

## Hosting
Upload this folder to a static web host. Use HTTPS and enable byte-range requests for MP4 playback. No build step or backend is required. This package has not been newly published.

## Media and dependencies
Five local 12-second HD previews preload the next clip. A browser may require a tap to enable sound. Google Fonts needs an internet connection; system font fallbacks are supplied. Streaming service destinations require internet access. Original user media is preserved separately.

## Verification
Checked local asset references, unique HTML IDs, internal anchors, JavaScript syntax, and representative phone/desktop browser sizes. Preview audio/video streams and automatic progression were checked. These are browser checks, not physical-device certification. External platform availability can change.
